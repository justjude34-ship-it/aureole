# Aureole

One file. Buy once, own forever.

**Live:** https://justjude34-ship-it.github.io/aureole/

Open `index.html` in any browser. No install, no account, no server. Works offline after the first open.

## What is inside

- Full-screen mandalas: Original, Fuchsia, Purple, Hypnotic
- Studio binaural beds: Relax, Sleep, Meditate, Deep (4 Hz)
- Timer: continuous, 15, 30, or 60 minutes, with a soft fade-out
- Sound beds: heartbeat, ocean, breath — each with a wide volume range
- Breath practices: Spirit, Heart, Box, 4-7-8, Coherent, Calm, Sigh, Open
- Add your own music
- Glass controls, tap the mandala to hide them
- App cover on open

Headphones help the binaural beat lock in.

This is a calm practice tool, not medical treatment.
